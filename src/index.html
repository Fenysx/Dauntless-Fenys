Administrador — gerar convite

API REAL

Entre com um perfil de administrador para gerar um convite.

Selecione sua chave administradora em Configurações. O servidor deve usar REGISTRATION_MODE=INVITECODE. O convite vale para uma pessoa.

Amigos devem criar a conta na tela inicial do Fenys. Use Sair / Trocar perfil para cadastrar outra pessoa neste PC.

PREFERÊNCIAS

Configurações

Selecione o executável do jogo e o servidor Fenys.

Para jogar com amigos, use o IP 100.x.y.z ou hostname *.ts.net do Tailscale. Nunca encaminhe a porta 61001 à internet.

Não selecionada

Se você já tem uma conta e apenas mudou para o IP Tailscale, selecione sua chave anterior. O Fenys verificará a conta no servidor antes de vinculá-la.

Não selecionada

A chave do administrador fica no PC; ela não é mostrada na interface nem enviada ao GitHub.

—
Não configurado

No modo remoto, o Fenys não inicia nem encerra serviços. A conexão exige Tailscale funcionando no host e no cliente.
