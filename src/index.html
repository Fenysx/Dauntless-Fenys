Hospedar um servidor — integração Google e comunidade
                  
Verificando a configuração deste host…

                  
Estas opções são exclusivas de quem administra um servidor. Para jogar, use apenas Escolher servidor.

                  
1. Integrar os personagens com Google

                  
Cada host tem identidade própria e utiliza o Supabase para persistência. O primeiro host usa a autorização inicial; os demais recebem uma autorização de outro host. Não compartilhe a chave privada do servidor.

                  

                    
                    
Na rede local, utilize um dos endereços IPv4 sugeridos deste computador, com a porta 61000. 127.0.0.1 não é cadastrado como host LAN no Supabase. Não publique essa porta na internet.

                    
Use certificado válido para o domínio/IP. Encaminhe a porta HTTPS e UDP 8770–8777 ao host. Uma conexão sob CGNAT precisa de IP público ou VPS. Consulte o guia de redes.

                    

                  
Mantenha todos fora do jogo. Quem já tem personagem deve vinculá-lo no servidor de origem antes da primeira troca; a integração não cria outro por cima do personagem antigo.

                  

                  

                    
2. Publicar servidor na comunidade

                    
Este passo só fica disponível após integrar o host em modo Internet — HTTPS, com IPv4 público e portas de partida configuradas. É possível hospedar numa VPS ou num computador da comunidade. A publicação exige a conta Google do administrador e a chave administrativa local.
