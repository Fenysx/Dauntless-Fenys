Use esta opção apenas para migrar uma chave de personagem anterior. O acesso normal é feito com Google; não crie outro personagem por cima do existente.

Padrão do Wine

            
Use um ambiente já configurado com winecfg e as dependências gráficas do jogo. Esta opção inicia o cliente pelo Wine; Proton e hospedagem de partidas no Linux ainda não foram integrados.
