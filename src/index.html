1 UTILIZAÇÃO

O código reúne o endereço Tailscale deste servidor e um convite de cadastro. Ele não transfere personagens entre bancos diferentes.

Seu Metagame deve responder nesse endereço pela rede Tailscale. Não use 127.0.0.1.
Ajuda a identificar para quem o convite foi criado.
Compartilhe apenas com a pessoa convidada.

Aguardando a verificação do servidor…

Os convites são emitidos pelo Metagame e só servem para registrar novas contas nele. Para preservar o mesmo personagem em outro servidor, os dados desse personagem precisam estar disponíveis no Metagame de destino. A chave da conta administradora nunca aparece no código.
